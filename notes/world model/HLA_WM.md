# 论文解析树：HLA-WM: Hybrid Linear Attention for Long-Horizon Video World Models

## 1. Background

**Task and application**：长时程视频世界模型旨在通过自回归生成模拟环境动态，支持智能体预测未来观测、推理动作后果，以及相机轨迹控制下的长时序交互式场景仿真。核心需求是：当相机离开某场景很久后再次返回时，生成的画面需与首次访问保持空间结构、物体布局的一致性，即**长程重访一致性**。

**Previous methods and technical challenges**:

### Challenge 1: 全历史 KV 缓存方案

- **Previous method**: 基于 Softmax 注意力的视频生成方法，通过持续增长的 KV 缓存保留完整的生成历史 token，提供对过去所有观测的直接访问。
- **Failure case / limitation**: 存储成本随生成序列长度线性增长，60 秒上下文需占用 25.82 GiB 显存，无法支撑分钟级以上的长时程 rollout，部署成本极高。
- **Technical reason**: KV 缓存以 token 为单位存储，序列越长、分辨率越高，缓存体量越大，内存开销随生成时长持续膨胀，缺乏可扩展性。

### Challenge 2: 循环线性注意力（Gated DeltaNet, GDN）方案

- **Previous method**: 基于循环线性注意力的 GDN 架构，将全部历史信息压缩为固定大小的循环状态，通过数据依赖的门控衰减和 delta 规则更新状态，内存成本不随序列长度增长。
- **Failure case / limitation**: 存在严重的**长程遗忘问题**：随着重访时间间隔增大，重访画面与首次访问的 SSIM、PSNR 持续下降；例如相机离开 Chunk 3 场景后，到 Chunk 35 重回时，Chunk 3 信息的保留度仅为 0.0416，生成的场景结构、物体排布出现明显漂移。
- **Technical reason**: ① 全部历史被压缩到单个循环状态中，早期场景的信息必须依次经过所有后续块的状态转移矩阵变换，无关中间场景的转移会持续衰减早期信息；② 状态更新严格遵循时间顺序，但世界模型中记忆的相关性由空间几何邻近度决定，时间推进与空间相关性存在本质错配，导致远处但相关的场景信息被无意义地持续削弱。

**Our pipeline / solution**:

- **Key innovation**: 提出无需训练的混合线性注意力框架 HLA-WM，将单一累积 GDN 内存替换为可独立寻址的分块仿射内存，通过相机几何引导检索相关历史块并选择性重组循环状态，在单循环状态与全 token KV 缓存之间建立了选择性可寻址的中间内存机制。
- **模块/贡献 1: 分块 GDN 内存** 解决了单一循环状态下历史信息无法独立寻址、被持续串行衰减的痛点；将视频序列切分为时间块，利用 GDN 的仿射结构为每个块缓存独立的状态转移摘要，支持任意子集的高效组合。优势是保留块内完整 GDN 动力学的同时，实现了历史记忆的分块可寻址，且无需重新训练模型。
- **模块/贡献 2: 几何引导的内存检索** 解决了时序更新与空间相关性错配的痛点；仅通过相机位姿、内参和场景深度代理计算视锥重叠度，检索与当前视角空间最相关的历史块，同时保留全局锚点块和最近上下文。优势是轻量无学习、精准过滤无关中间场景，从根源减少信息衰减。
- **模块/贡献 3: 选择性状态重组** 解决了无关中间转移导致的长程信息衰减问题；将检索到的块按时间顺序重组为查询专用的循环状态，仅对主 GDN 内存做选择性改造。优势是让远处相关记忆绕过大量无关变换，大幅提升保留度，同时推理开销极低。

**Demos / applications**: 在室内、户外城市、户外自然、游戏风格等四类场景的长时重访案例中，展示了相机远离后重回旧视角时的画面一致性：基线模型出现明显的场景结构漂移、物体布局变化，HLA-WM 更准确地保留了走廊几何、街道布局、地形轮廓、书架排列等空间特征。

## 2. Method

### Overview

- **任务**: 在不重新训练的前提下，为基于 GDN 的视频世界模型提升长程场景重访一致性，同时保持内存高效性与推理速度。
- **输入**: 预训练 SANA-WM 模型、预设相机轨迹与内参、场景级中位深度代理。
- **输出**: 每个时间块对应的查询专用 GDN 循环状态，用于生成当前块视频，最终输出长时一致的自回归视频序列。
- **整体流程**:
    1. 预计算所有时间块两两之间的视锥重叠分数；
    2. 初始化分块 GDN 摘要缓存库与原生流式状态；
    3. 遍历每个待生成的查询块： ① 根据块内相机转向幅度，动态确定最近上下文窗口大小； ② 组合持久 sink 块、自适应最近上下文块、几何检索 Top-K 历史块，得到选中历史集合； ③ 将选中块按时间排序，通过仿射组合规则重组出查询专用的历史循环状态； ④ 用重组后的状态生成当前视频块； ⑤ 缓存当前块的仿射摘要，按原生时序更新相机 GDN 与局部卷积状态。

---

### Pipeline module 1: 分块 GDN 内存（Chunk-wise GDN Memory）

- **Motivation**: 单一循环状态下所有历史信息串行传递，早期信息被后续转移持续衰减；需要将历史拆分为可独立寻址的单元，同时保留 GDN 的数学完备性以支持高效状态重组。
- **做法**:
    1. 将 GDN 的 token 级更新公式整理为仿射形式 ( S_t = S_{t-1} A_t + B_t )，其中 ( A_t ) 控制状态转移与衰减，( B_t ) 代表当前 token 写入的新信息；
    2. 将连续 L 个 token 聚合为一个时间块，将块内所有 token 的仿射变换按顺序累乘合并，得到整个块的仿射摘要 ( (A_i, B_i) )；
    3. 每个块生成后独立缓存其仿射摘要，与输入循环状态无关；
    4. 块之间满足结合律的组合规则：( (A_i,B_i) * (A_j,B_j) = (A_i A_j,\ B_i A_j + B_j) )，可直接按顺序合成任意多块的总效应。
- **为什么能 work**: GDN 本身天然具备仿射数学结构，块级摘要完整等价于块内逐 token 更新的累积效果，数学上严格保真；独立缓存让每个块的记忆可以被单独访问、筛选和组合。
- **Technical advantage**:
    - 内存粒度从 token 级降为块级，存储开销大幅降低；
    - 支持任意历史子集的直接重组，无需重跑 Transformer 前向传播；
    - 完全兼容预训练 GDN 参数，无需额外训练或微调。

---

### Pipeline module 2: 几何引导的内存检索（Geometry-Guided Memory Retrieval）

- **Motivation**: 世界模型中记忆的价值由空间视角重叠度决定，而非时间远近；纯时序更新会将大量无关中间场景的变换施加到有用历史上，造成无意义的信息衰减。
- **做法**:
    1. 对每个块，在图像平面均匀采样 7×7 网格点，结合场景中位深度的三个代理深度（0.5 d_med、d_med、1.5 d_med）生成 3 D 代理点；
    2. 通过相机外参将代理点转换到世界坐标系，再投影到另一块的相机平面，计算双向可见比例，得到对称视锥重叠分数 ( (R(i,j)) )；
    3. 固定保留第 0 块作为 sink（全局场景锚点），保留最近 1 块保障局部时序连续性；
    4. 从剩余历史块中检索 Top-K 个重叠分数最高的块；
    5. 当块内相机平移方向转角超过 25°阈值时，临时将最近上下文扩展为 3 块，提升相机突变时的鲁棒性。
- **为什么能 work**: 视锥重叠程度直接反映两个视角看到的场景区域重合度，几何相关性越高的历史块，对当前视角生成的参考价值越强；sink 块提供全局空间基准，最近块保障短程时序平滑。
- **Technical advantage**:
    - 仅依赖相机元数据，无需生成 RGB 图像、光流或语义特征，计算开销极低；
    - 用空间相关性筛选记忆，从根源上减少无关中间转移的衰减作用；
    - 转向自适应的最近上下文机制，兼顾长程检索能力与局部运动连续性。

---

### Pipeline module 3: 选择性状态重组（Selective State Recomposition）

- **Motivation**: 即使检索到了相关历史块，若按完整时序重组仍会包含无关中间块的转移，无法彻底解决衰减问题；需要只组合选中块，让相关记忆绕过无关变换。
- **做法**:
    1. 将选中的所有块（sink + 检索历史块 + 最近块）按原始时间顺序排列；
    2. 按顺序通过仿射组合规则，依次合成所有选中块的总转移矩阵与总写入项；
    3. 结合初始 GDN 状态 ( S_0 )，计算出查询专用的历史循环状态 ( S_q^{hist} = S_0 A_{\pi_q} + B_{\pi_q} )；
    4. 仅替换主 GDN 的循环状态，相机 GDN 状态、局部卷积状态、FFN 时序卷积状态仍保持原生时序更新；
    5. 对配套的 Softmax KV 缓存也应用相同的选中块集合，保持两个记忆通路的一致性。
- **为什么能 work**: 跳过了几何无关的中间块，早期相关场景的信息只需经过少数选中块的转移，大幅减少了衰减次数；按时间顺序组合保证了 GDN 动力学的正确性，没有破坏循环状态的内在逻辑。
- **Technical advantage**:
    - 远处相关记忆的保留度显著提升，从根源缓解长程遗忘；
    - 直接操作缓存的仿射摘要，无需重编码历史帧，推理开销极小；
    - 仅修改主 GDN 通路，其他模块保持原生运行，兼容性强。

## 3. Experiments

### Comparison experiment

- **Baselines**: 原生 SANA-WM（基于 GDN 的基线世界模型），分别在 Stage-1（自回归生成）、Stage-1+AR 精炼、Stage-1+双向精炼三种生成模式下进行对比。
- **Datasets / tasks**:
    1. **SANA-WM-Bench**：包含简单/困难两种轨迹拆分，各 80 条相机控制轨迹，覆盖室内、户外城市、户外自然、游戏风格 4 类场景，每条轨迹 60 秒共 961 帧；核心任务是长时程生成下的重访一致性与相机可控性。
    2. **MBench-A**：共 547 个样本，包含 Causal、Human、Environment、Object 4 个官方子集；核心任务是验证方法在多样场景与交互模式下的泛化能力。
- **Metrics**:
    - 重访一致性：PSNR、SSIM（越高越好），LPIPS（越低越好）；
    - 相机可控性：旋转误差 RotErr、平移误差 TransErr、相机运动一致性 CamMC（均越低越好）；
    - 效率：推理吞吐量 FPS、历史状态内存占用。
- **Results**:
    1. **长程重访一致性全面提升**：在两个基准、所有生成模式下，HLA-WM 的三项重访指标均优于基线；SANA-WM-Bench 困难轨迹下 Stage-1 阶段 PSNR 提升 0.74 dB，旋转误差降低 26%；MBench-A 上全部 4 个子集、3 种生成模式下，三项重访指标均一致提升。
    2. **相机可控性同步改善**：Stage-1 阶段旋转误差最高降低 31%，场景结构漂移减少，空间参考更稳定；下游精炼后大部分场景下相机控制指标仍保持优势。
    3. **效率优势显著**：60 秒上下文下历史状态内存仅 2.15 GiB，比全 KV 缓存减少 12 倍；推理吞吐量最多仅下降 1.6%，几乎可忽略。
    4. **精准匹配长程痛点**：重访时间间隔越长，HLA-WM 相对基线的提升幅度越大，中长间隔（10 秒以上）的增益显著高于短间隔，对应解决了长程遗忘的核心问题。

### Ablation studies

- **模块 A：Sink 块消融（w/o Sink）**
    - 变化：移除作为全局锚点的首块后，PSNR、SSIM 下降，LPIPS 上升，所有相机控制指标均退化。
    - 证明：持久 sink 块提供了全局场景基准，对维持整体空间一致性与相机稳定性不可或缺。
- **模块 B：选择性转移 A 消融（w/o Select A）**
    - 变化：保留所有历史块的转移项 A，仅选择性组合写入项 B；PSNR、SSIM 明显下降，相机误差上升。
    - 证明：无关中间块的转移矩阵是造成长程信息衰减的核心原因，选择性跳过转移项是性能提升的关键。
- **模块 C：选择性写入 B 消融（w/o Select B）**
    - 变化：保留所有历史块的写入项 B，仅选择性组合转移项 A；性能同样全面退化。
    - 证明：选择性过滤写入项同样重要，剔除无关场景的写入信息可减少记忆干扰。
- **模块 D：转向感知上下文消融（w/o Turn-aware）**
    - 变化：移除转向时扩展最近上下文的机制；重访一致性下降，相机控制效果变差。
    - 证明：自适应最近上下文在相机突变时保障了局部时序连续性，避免检索引入的画面跳变。
- **模块 E：GDN 通路与 KV 通路分离消融**
    - 变化：分别测试仅改造 GDN 通路（GDN-only）、仅改造 KV 缓存通路（KV-only）、两者同时改造（完整 HLA-WM）。
    - 结果：GDN-only 已贡献主要的重访一致性提升，KV-only 提升幅度较小；两者结合的完整方法效果最优，且 KV 对齐能稳定相机控制，缓解 GDN 单独改造带来的通路不匹配。
    - 证明：GDN 状态重组是长程记忆提升的主要来源，KV 缓存对齐起互补的稳定作用。
- **模块 F：检索预算 K 消融**
    - 变化：测试 K=1、3、4、5 时的性能。
    - 结果：K=1 时重访一致性指标最优，增大 K 没有持续提升，仅部分相机控制指标略有改善。
    - 证明：单个高相关历史块已足以支撑有效的长程回忆，更小的 K 兼顾了效果与效率。
- **模块 G：检索策略对比消融**
    - 变化：对比随机选择、最近选择、均匀时间采样、几何引导四种策略。
    - 结果：均匀采样优于随机和纯最近策略，几何引导进一步提升所有重访一致性指标。
    - 证明：空间几何相关性是比时间均匀采样更有效的记忆检索信号。

## 4. Limitation

### 失败场景

1. 作为无训练的即插即用方案，性能提升受限于基线预训练模型，无法达到训练级别的增益上限；
2. 检索仅依赖相机视锥重叠代理，未考虑遮挡、实际可见性差异与语义相关性，在严重遮挡、语义重要但视觉重叠小的场景中检索精度受限；
3. 依赖预设的相机位姿元数据，仅适用于相机可控的世界模型，无法直接应用于无轨迹约束的自由长视频生成。

### 原因分析

1. 方法定位为推理时的内存改造框架，不修改模型参数，因此性能上限由基线模型的原生能力决定；
2. 为了保持轻量高效，检索采用了极简的视锥重叠代理，未引入深度估计、语义分割等重感知模块，在复杂场景下存在精度妥协；
3. 几何检索的输入信号是相机轨迹，这是相机控制世界模型的天然优势，但也限制了方法的适用场景。

### 未来改进方向

1. 将选择性状态检索机制整合到训练过程中，让模型学习更优的长程记忆保存与调用方式，突破无训练的性能上限；
2. 引入更丰富的检索信号，如遮挡建模、语义特征匹配，提升复杂场景下检索的鲁棒性与精准度；
3. 探索无需相机位姿的检索机制，如基于视觉特征匹配的块检索，将方法拓展到更通用的长视频生成场景。
